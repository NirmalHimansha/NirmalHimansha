Purpose & Overview

🔓 Public Access — No Login Required: This homepage and the privacy policy are publicly accessible without any authentication, login, cookies, tracking, or paywall. Anyone can view these pages at any time at https://www.nirmal.cc/apocalypse-shorts.html and https://www.nirmal.cc/apocalypse-shorts-privacy.html.

Apocalypse Survival Shorts is an open-source automation pipeline that creates and publishes daily YouTube Shorts about post-apocalyptic survival scenarios. The system runs entirely on the creator's local hardware (laptop) and uses a combination of local large language models and affordable cloud AI services to generate unique, educational survival content every day without any human intervention.

What this application does:

  • Generates daily 45-second narration scripts about survival topics (10 rotating themes: Zombie Outbreak, Nuclear Aftermath, Wild Survival, Urban Ruins, Winter Apocalypse, Water Purification, Emergency Communications, Abandoned Bunkers, Wasteland Navigation, Fire Craft)
  • Creates AI-generated video clips using Stable Video Diffusion via Replicate API
  • Stitches intro + AI video + outro into a complete YouTube Short using FFmpeg
  • Uploads the final video to the creator's YouTube channel via YouTube Data API v3 (OAuth 2.0)
  • Sends a private Telegram notification to the creator with the video URL

What this application does NOT do:

  • Does not serve the public — it has no public-facing interface, no user accounts, no registration
  • Does not collect data from viewers, website visitors, or any third parties
  • Does not process personal information from anyone except the creator's own API credentials
  • Does not use analytics, tracking, advertising, or crash reporting services
  • Does not generate AI NCII (non-consensual intimate imagery) — content is strictly educational survival material

The application serves a single user — the content creator (Nirmal Himansha) — who operates the pipeline to maintain a YouTube channel focused on survival education.

Google OAuth Compliance: This homepage is publicly accessible without authentication. The application name "Apocalypse Survival Shorts" matches exactly the name configured in the Google Cloud Console OAuth consent screen. The privacy policy is available at /apocalypse-shorts-privacy.html.

Technical Architecture

The pipeline is built as a modular Python application with clear separation of concerns:

Python 3.10+ Custom LLM API (localhost:31415) Replicate API (Stable Video Diffusion) FFmpeg 6.x (Video Stitching) YouTube Data API v3 (OAuth 2.0) Telegram Bot API SQLite (SHA-256 Deduplication) Schedule Library (Daily Cron) PyYAML (Configuration) OpenAI Python SDK (LLM Client) Google API Python Client Requests (HTTP)

Automated Pipeline Flow

Each daily execution follows this deterministic sequence:

1. Theme Selection

Rotates through 10 themes based on day-of-year for consistent daily variety.

2. Prompt Construction

Loads template from templates/script_prompt.txt and injects theme variable.

3. Script Generation

Calls local LLM at http://127.0.0.1:31415/v1 (OpenAI-compatible) to generate 45-second narration script.

4. Deduplication Check

Computes SHA-256 hash of script; queries SQLite DB; retries with alternative theme if duplicate.

5. Script Persistence

Saves script to scripts/YYYY-MM-DD_theme.md and records hash in deduplication DB.

6. Video Generation

Sends visual prompt to Replicate API (Stable Video Diffusion); polls for completion; downloads MP4.

7. Fallback Handling

If AI video fails, generates solid-color clip locally via FFmpeg (no external dependency).

8. Video Stitching

FFmpeg concatenates intro.mp4 + generated clip + outro.mp4 with codec-safe re-encoding.

9. YouTube Upload

OAuth 2.0 authenticated upload via YouTube Data API v3 as Short with title, description, tags.

10. Notification

Telegram Bot API sends video URL, title, and timestamp to creator's private chat.

Configuration & Deployment

All configuration resides in config.yaml (not committed to version control). The pipeline requires:

  • LLM API: OpenAI-compatible endpoint at http://127.0.0.1:31415/v1 with API key
  • Video Service: Replicate API key for Stable Video Diffusion
  • YouTube OAuth: client_secret.json from Google Cloud Console (OAuth 2.0 Desktop App)
  • Telegram Bot: Bot token from @BotFather and numeric chat ID
  • Assets: intro.mp4 and outro.mp4 (2-second branded bumpers)

Execution: python scripts/scheduler.py --once (single run) or --schedule (daily at 02:00).
